웹 접속 따라가기

7단계 · 직접 눌러 살펴보기

집 컴퓨터에서 웹사이트에 접속하는 IPv4·이더넷·TCP 기반 HTTPS(HTTP/1.1, TLS 1.3) 예시입니다. 실제 패킷 캡처가 아닌 학습용 시각화이며, 사설·문서용 IP와 가상의 MAC을 사용합니다.

설명 순서와 캐시 알아보기

아래는 설명 순서입니다. DNS 조회 안에서도 목적지 판단과 필요한 MAC 확인·전달이 일어납니다. DHCP는 사전 설정이며, 유효한 설정·DNS 캐시·ARP 캐시가 있으면 매번 새로 교환하지 않습니다.
